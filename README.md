# Optimal Compilation of Hopf Differential Frames

### A structured unitary completion at the optimal state-preparation frontier

Exact quantum state preparation fixes one column of a unitary. Controlled state
preparation fixes a family of state columns on an indexed input subspace.
General unitary synthesis fixes every column of an otherwise unstructured
unitary.

The Hopf differential frame lies between these familiar tasks. It is a complete
unitary whose first column is an arbitrary state and whose designated remaining
columns are coordinate directions of that state. The full frame is fixed, but
it is generated by only `O(2^n)` parameters and has a balanced binary-tree
factorization.

This repository proves that the structured completion can be compiled at the
same asymptotic size–depth frontier as arbitrary state preparation.

## Main theorem

Let

```math
N=2^n
```

and let `m>=0` be the number of clean ancillary qubits supplied to the compiler.
In the exact all-to-all logical model with arbitrary one-qubit gates and CNOTs,

```math
\boxed{
S_{\mathbb R}(n,m)
=S_{\mathbb C,\mathrm{mag}}(n,m)
=\Theta(N)
}
```

and

```math
\boxed{
D_{\mathbb R}(n,m)
=D_{\mathbb C,\mathrm{mag}}(n,m)
=\Theta\left(n+\frac{N}{n+m}\right).
}
```

Here `W_R` is the real Hopf differential frame and

```math
W_{\mathbb C,\mathrm{mag}}=D_{\mathrm{ph}}W_{\mathbb R}
```

is the phase-dressed complex magnitude frame. The complex leaf-phase
derivatives use a separate direct measurement stream and are not additional
columns of the same `N`-dimensional unitary.

The circuits use at most the requested `m` clean ancillary qubits and return all
of them exactly to zero.

## Where this problem sits

| Task | Required transformation | Freedom left to the compiler |
|---|---|---|
| QSP | `|0^n> -> |psi>` | every other input column is free |
| CQSP | `|i>|0^n> -> |i>|psi_i>` | action outside the indexed preparation subspace is free |
| **Hopf differential-frame compilation** | `|0^n> -> |psi>` and `|lambda(j)> -> |e_j>` for all frame markers | no freedom on the logical frame, but the unitary has `O(N)` tree structure |
| General unitary synthesis | `|x> -> U|x>` for every basis label `x` | no structural promise |

The central question is therefore not whether the state can be prepared. It is
whether a particular structured completion can retain the optimal QSP frontier.

## The three points carrying the proof

### 1. The compiler contract is stronger than state preparation

A valid frame compiler must satisfy

```math
\widetilde W\bigl(|\varphi\rangle|0^m\rangle\bigr)
=(W|\varphi\rangle)|0^m\rangle
```

for every system input `|varphi>`. Equality only on `|0^n>` is insufficient.
The repository includes a two-qubit example in which two unitaries prepare the
same state, but one exchanges two marker columns and changes the decoded
gradient from

```math
(2,0,0)
\quad\longmapsto\quad
(0,\sqrt2,0).
```

### 2. Zero workspace is closed by an in-place echo

At one nonfinal Hopf depth, the upper prefix selects a rotation and the complete
lower suffix supplies one shared all-zero predicate. When no clean flag is
available, one original suffix data qubit temporarily carries that predicate.
A half-angle/Pauli echo applies the intended rotation on the original
zero-suffix sector, cancels it on every other sector, and restores the borrowed
logical qubit exactly.

This gives

```math
S_{\mathbb R}(n,0)=\Theta(N),
\qquad
D_{\mathbb R}(n,0)=\Theta\left(n+\frac{N}{n}\right).
```

### 3. Positive workspace is converted into coherent tree parallelism

For small positive `m`, one reusable clean flag stores the suffix predicate.
For larger `m`, the Hopf tree is cut after `t` levels. A clean binary–one-hot
decoder implements the conditioned prefix, while an explicit CNOT/Fredkin
router moves the suffix coherently into the prefix-selected branch. The disjoint
subtree frames then run in parallel and the complete route is reversed.

The largest feasible cut yields the denominator `n+m` in the optimal depth.

## State-preparation results used here

The active external framework is

> P. Yuan and S. Zhang, “Optimal (controlled) quantum state preparation and
> improved unitary synthesis by quantum circuits with any number of ancillary
> qubits,” *Quantum* **7**, 956 (2023).

The proof uses the following results exactly in their declared standard-circuit
model.

| Result | Role in the Hopf-frame proof |
|---|---|
| Theorem 2 | target all-workspace QSP frontier and comparison benchmark |
| Lemma 5 | exact ancilla-free multi-controlled `X` for predicate toggles |
| Lemma 6 | exact UCG size–depth tradeoff for half-angle, flagged, subtree, and phase gates |
| Lemma 9 | coherent CNOT-tree copy–use–uncopy |

The earlier state-preparation paper is retained as the historical predecessor.
The two papers are treated here as one coherent compiler line: the later theorem
provides the uniform all-workspace framework, while the earlier work records the
preceding ancilla–depth landscape and origins of selected primitives.

Most of the circuit machinery is familiar. The Hopf-specific work is to expose
the complete frame in a form that lets those primitives act without releasing
the prescribed marker columns.

## What is established here

The project-specific theorem chain is:

1. complete frame safety is the correct compiler contract for the inverse-frame
   gradient record;
2. state-column equality is strictly weaker;
3. every addressed Hopf depth has an optimal ancilla-free implementation;
4. a clean decoder and coherent router realize the positive-workspace tree cut;
5. the real and phase-dressed complex magnitude frames match the optimal QSP
   frontier for every `m>=0`;
6. the inverse-frame part of Hopf QBP therefore introduces no additional
   asymptotic compilation-depth factor.

The narrow strict-zero contribution is the reduction of one addressed depth to
two total-width-`d+2` UCGs and linear predicate toggles using one restored
original suffix qubit. The repository does not claim invention of UCGs,
controlled-unitary square roots, borrowed qubits, or toggle-detection ideas.

## Verification

The executable support includes:

- independent recursive and addressed-layer frame constructions;
- the complete two-qubit state-column obstruction;
- complete-operator tests of the strict-zero echo;
- explicit X/CNOT/Toffoli layers for the binary–one-hot decoder;
- explicit CNOT/Fredkin routing on arbitrary complex prefix–suffix-entangled
  inputs;
- branch-flag, control-copy, token, and data-register cleanup;
- integer and exact-rational resource inequalities;
- magnitude and direct-phase decoder checks.

The elementary UCG and multi-controlled-`X` decompositions are imported from
the cited state-preparation framework rather than regenerated locally. Finite
checks support the construction and conventions; the asymptotic theorem rests
on the analytic proof.

## Scope

The result is an exact logical-circuit theorem. It does not address hardware
connectivity, native-gate scheduling, approximate Clifford+T synthesis, noise,
optimizer convergence, or an application-independent cost for controlled
observable access.
